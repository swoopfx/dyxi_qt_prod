# Dyxi Phonics - Standalone Qt 6.10 C++/QML Project

This standalone C++ and QML project was generated by DYXI Phonics. It is fully compatible with Qt 6.10.

## Project Structure
- `CMakeLists.txt`: Modern CMake build configuration compatible with Qt 6.10.
- `main.cpp`: Application entry point booting the Qt Quick module and loading QML.
- `audio_synth.h` / `audio_synth.cpp`: Non-blocking C++ sound synthesizer using Qt 6 `QAudioSink`.
- `main.qml`: High-fidelity multi-sensory dyslexia-friendly phonics companion interface.
- `DyxiLogoShape.qml`: Beautiful SVG butterfly vector logo compiled using Qt Quick Shapes.

## Prerequisites
Make sure you have Qt 6.10 (or later) and CMake (version 3.16+) installed on your machine.

## How to Compile & Build standalone
Using CMake and standard compiler systems, run the following commands:

```bash
# 1. Configure the project build directory
cmake -B build -G "Ninja"

# 2. Build the executable
cmake --build build

# 3. Run the compiled application
./build/appDyxiPhonics
```
